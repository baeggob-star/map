# 🚇 부산 지하철 역별 이용객 지도 분석 앱

파이썬 기반의 데이터 분석 및 시각화 웹 애플리케이션입니다. 
부산 지하철 탑승객 데이터를 업로드하면, 지도 상에서 역별 이용객 분포와 호선별 데이터를 직관적으로 확인할 수 있습니다.

## 🌟 주요 기능
* **데이터 업로드**: CSV 파일을 업로드하여 전체 데이터를 표 형태로 미리보기 할 수 있습니다.
* **호선 필터링**: 다중 선택(Multiselect) 기능을 통해 원하는 지하철 호선만 지도에 표시할 수 있습니다.
* **TOP 5 랭킹**: 선택한 호선 중 이용객이 가장 많은 상위 5개 역을 자동으로 추출하여 표로 보여줍니다.
* **지도 시각화**: 
  * 이용객 수에 비례하여 지도 위 마커(원)의 크기가 다르게 표시됩니다.
  * 호선별로 마커 색상이 다르게 적용됩니다 (1호선 주황, 2호선 초록, 3호선 갈색, 4호선 파랑).
  * 마커에 마우스를 올리면 역명이 나타나고, 클릭하면 상세 이용객 수를 확인할 수 있습니다.

## 🛠️ 사용 기술 (Tech Stack)
* **Language**: Python
* **Web Framework**: Streamlit
* **Data Analysis**: Pandas
* **Map Visualization**: Folium, streamlit-folium
